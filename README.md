# DVT A2A Marketplace

Plugin marketplace for Claude Code — A2A (Agent-to-Agent) protocol tools.

## How to install

In Claude Desktop (Cowork), go to **Directory → Add marketplace → Add from repository** and paste this repo URL.

Then install **dvt-a2a-client** from the directory.

## Available plugins

| Plugin | Description |
|---|---|
| **dvt-a2a-client** | A2A protocol client — discover agents, send messages, manage tasks, stream responses |

## Usage

Once installed, you can use the following tools in any Claude session:

- `a2a_discover` — Discover an agent's capabilities
- `a2a_send_message` — Send a message to an A2A agent
- `a2a_send_data` — Send structured JSON data
- `a2a_stream_message` — Stream responses from an agent
- `a2a_send_and_wait` — Send and wait for completion
- `a2a_get_task` — Get task status
- `a2a_cancel_task` — Cancel a running task
- `a2a_list_tasks` — List tasks
